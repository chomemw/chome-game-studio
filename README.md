# CHOME Game Studio

An independent game studio creating original puzzle games, adventures, and playful worlds.

## Playable games

- **Fruit Fancy** — fruit-connecting puzzle adventure with player profiles, cloud saves, leaderboards, and the shared CHOX rewards wallet.
- **CHOME Blocks** — original 8×8 block-placement puzzle with tap and drag controls, score combos, local progress, and signed-in cloud saves.

## Player system

The Player Hub provides account registration, sign-in, profiles, avatar uploads, a shared CHOX wallet, and access to studio games. Guests can browse and play; signing in enables cloud progress and wallet access.

## Current CHOME Blocks scope

The first playable version includes an 8×8 board, 15 original shape patterns, row/column clears, score and best-score tracking, combo bonuses, sound controls, restart, and cloud save support. CHOX earning rules and ranked score submission are not enabled for CHOME Blocks yet; these will be connected after the game's level/reward rules are defined.
