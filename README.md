# chome-game-studio
 An independent game studio creating immersive 3D adventures, original worlds, and exciting gaming experiences.

## CHOME Player System

Players can browse the studio and play games as guests. The Player page provides account registration, sign-in, profile details, and avatar uploads. Player accounts use the separate CHOME-PLAYER-SYSTEM Supabase project. Cloud saves, achievements, and leaderboards are planned for later stages.
